# التقارير — المواصفات

التصميم: `docs/design/png/Reports*.png` (والقيم الدقيقة في `.dc.html`). كل الحسابات **من القاعدة المحلية** (تعمل أوفلاين)، للفرع الحالي، بالعملة المختارة.

## الفترة (الفلتر)
- **الافتراضي عند الفتح: الشهر الحالي من السنة الحالية.** يُحفظ آخر اختيار أثناء الجلسة فقط؛ كل فتح جديد للتطبيق يرجع للشهر الحالي.
- نوع الفترة: **يوم / شهر / سنة** (تبويبات أعلى الشاشة) + **من – إلى** في نافذة الاختيار.
- السهمان ‹ › ينقلان للفترة السابقة/التالية حسب النوع. التالي معطّل إذا كانت الفترة الحالية.
- الضغط على اسم الفترة يفتح **نافذة الاختيار**: السنوات (من أول حركة في الفرع حتى السنة الحالية) + شبكة 12 شهراً، تحت كل شهر تحصيله بالألف، والأشهر القادمة معطلة. زر «الشهر الحالي» للرجوع السريع.
- شريط الأشهر الأفقي تحت السهمين: آخر 6–12 شهراً للتنقل بضغطة.
- عرض اليوم: شريط أيام الأسبوع، ونقطة تحت كل يوم فيه حركات.
- الضغط على يوم في رسم الشهر يفتح عرض اليوم، والضغط على شهر في رسم السنة يفتح عرض الشهر.
- الفترة الحالية جزئية: يُكتب «1 – 17 نوفمبر · الشهر الحالي»، والمقارنة بالشهر السابق تكون **لنفس عدد الأيام** (1–17 أكتوبر) حتى لا تكون مضللة.

## المحتوى
| القسم | الحساب |
| --- | --- |
| الديون نهاية الفترة / بدايتها | `Ledger.balancesAsOf` لكل زبون عند آخر يوم في الفترة وقبل أولها |
| التحصيل / ديون جديدة + المقارنة | مجموع السداد (payment + paymentFx بقيمة العملة المختارة) والدين، مع استبعاد الملغى والحركات الفاشلة |
| نسبة التحصيل | التحصيل ÷ الديون الجديدة |
| الحركة اليومية | لكل يوم: تحصيل للأعلى (أخضر) وديون للأسفل (أحمر فاتح). أفضل يوم تحصيل |
| ملخص الحركات | العدد والمبلغ لكل نوع: سداد، دين، مرتجع، خصم، افتتاحي، إلغاء |
| وعود السداد | الوعود التي تاريخها داخل الفترة: وُفي بها / متأخرة / قادمة |
| الزبائن | تبويبات: الأكثر سداداً، الأكثر ديناً في الفترة، عليهم رصيد ولم يسددوا شيئاً في الفترة |
| حسب المستخدم | تحصيل وديون وعدد عمليات لكل مستخدم (`createdBy`) — يظهر للمالك فقط |
| أعمار الديون | `AgingBuckets` كما في نهاية الفترة |
| عرض اليوم | تحصيل/ديون/صافي، حسب الساعة، قائمة الحركات، «مشاركة ملخص اليوم» (نص واتساب) |
| عرض السنة | مجاميع السنة ومقارنة بالسابقة، زبائن جدد، متوسط مدة السداد، رسم 12 شهراً، قائمة الأشهر |

- التصدير: **PDF** بنفس الأقسام (عبر نافذة المشاركة) و**Excel** (حزمة `excel`، ورقة لكل قسم).
- الأداء: احسب في `compute`/Isolate عند السنة أو الفروع الكبيرة، واعرض هيكلاً (skeleton) أثناء الحساب.
- ضع منطق التجميع في `ajil_core` (`src/reports.dart`: `ReportPeriod` و`PeriodReport.build`) مع اختبارات، والشاشة تعرض فقط.
